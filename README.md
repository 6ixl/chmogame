# Чмога

Офлайн-сборник из 375 мини-игр для Android (HTML/JS + Capacitor). Работает полностью без интернета.

## Обновления
Приложение раз в сутки проверяет GitHub Releases (репозиторий `6ixl/chmogame`) и предлагает скачать новый APK. Вручную: ⚙ → «Проверить обновления». Прогресс при обновлении сохраняется (та же подпись и пакет).

Выпуск новой версии одной командой:
```powershell
powershell -File tools/release.ps1 1.4 "Что нового"
```
(bump версии → сборка → коммит → push → GitHub Release с APK).

## Резервная копия
⚙ → «Скопировать код бэкапа» кладёт весь прогресс в буфер обмена текстом; «Вставить код бэкапа» восстанавливает.

## Установка на телефон
1. Скопируйте `Чмога.apk` на телефон (кабель, Telegram «Избранное», Google Drive и т.п.).
2. Откройте файл, разрешите установку из неизвестных источников.
3. Обновление: соберите новый APK и установите поверх — прогресс сохранится (подпись та же).

## Разработка
- `www/` — весь код игры. Открыть в браузере: `npm run serve` → http://localhost:5173
- Тест всех игр headless + скриншоты: `node tools/test.js`; уровни на 30/100/250: `node tools/test_levels.js`; скриншоты выбранных игр: `node tools/shots.js flow checkers`
- Словарь/уровни: `python tools/build_dict.py` (нужны `tools/data/nouns.txt` и `freq.txt`)
- Иконка: `python tools/make_icon.py`, затем `npx @capacitor/assets generate --android`

## Сборка APK
Нужны JDK 21 (`C:\Program Files\Microsoft\jdk-21...`) и Android SDK (`C:\Android\sdk`).
```powershell
$env:JAVA_HOME = "C:\Program Files\Microsoft\jdk-21.0.12.101-hotspot"
$env:ANDROID_HOME = "C:\Android\sdk"
npx cap sync android
cd android
.\gradlew.bat assembleRelease --no-daemon
# результат: android\app\build\outputs\apk\release\app-release.apk
```
Ключ подписи: `android/chmogame.keystore` (пароль в `android/keystore.properties`). Не теряйте его — без него нельзя обновить установленное приложение.

## Игра по Wi-Fi (Карточная Арена)
Оба телефона в одной сети (общий Wi-Fi или раздача с одного из них), интернет не нужен:
1. Первый выбирает «Создать игру», копирует код и отправляет второму (любым способом).
2. Второй жмёт «Подключиться», вставляет код, получает ответный код и отправляет обратно.
3. Первый вставляет ответ — бой начинается. Хост считает бой, гость получает состояние 10 раз в секунду.
