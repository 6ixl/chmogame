# Чмогейм

Офлайн-сборник из 68 мини-игр для Android (HTML/JS + Capacitor). Работает полностью без интернета.

## Установка на телефон
1. Скопируйте `Чмогейм.apk` на телефон (кабель, Telegram «Избранное», Google Drive и т.п.).
2. Откройте файл, разрешите установку из неизвестных источников.
3. Обновление: соберите новый APK и установите поверх — прогресс сохранится (подпись та же).

## Игры (68)
- **Слова (11):** Слова (Words of Wonders, 400 уровней), Филворды, 5 букв, Анаграммы, Виселица, Пропущенная буква, Поиск слов, Наборщик, Буквенный дождь, Шифровка, Быстрое чтение
- **Головоломки (24):** 2048, Судоку, Мини-судоку, Сапёр, Пятнашки, Найди пару, Крестики-нолики, Нонограмма, Лампочки, Потоки, Ханойские башни, Мастермайнд, Быки и коровы, Лабиринт, Саймон, Найди лишнее, Таблица Шульте, Арифметика, Реакция, Сортировка, Трубопровод, Десяточка, Три в ряд, Пузыри
- **Настольные и карточные (10):** Четыре в ряд, Реверси, Точки и квадраты, Морской бой, Шашки, Двадцать одно, Кости, Больше-меньше, Камень-ножницы, Ним
- **Аркады (23):** Змейка, Монетный бег, Флаппи, Тетрис, Арканоид, Прыгун, Через дорогу, Космос, Посадка, Башня, Вертолёт, Динозаврик, Гонки, Тир, Ловля фруктов, Жонглёр, Аэрохоккей, Цветной прыжок, Плитки, Кликер, Цвет слова, Пинг-понг, Мини-гольф

Уровневые игры (Филворды, Нонограмма, Потоки, Лабиринт, Трубопровод и др.) генерируются процедурально — уровней не меньше 100, сложность растёт.

Монеты общие для всех игр: зарабатываются в любой игре, тратятся на подсказки в словесных.

## Разработка
- `www/` — весь код игры. Открыть в браузере: `npm run serve` → http://localhost:5173
- Тест всех игр headless + скриншоты: `node tools/test.js`; уровни на 30/100/250: `node tools/test_levels.js`; скриншоты выбранных игр: `node tools/shots.js flow checkers`
- Словарь/уровни: `python tools/build_dict.py` (нужны `tools/data/nouns.txt` и `freq.txt`)
- Иконка: `python tools/make_icon.py`, затем `npx @capacitor/assets generate --android`

## Сборка APK
Нужны JDK 21 (`C:\Program Files\Microsoft\jdk-21...`) и Android SDK (`C:\Android\sdk`).
```powershell
$env:JAVA_HOME = "C:\Program Files\Microsoft\jdk-21.0.12.101-hotspot"
$env:ANDROID_HOME = "C:\Android\sdk"
npx cap sync android
cd android
.\gradlew.bat assembleRelease --no-daemon
# результат: android\app\build\outputs\apk\release\app-release.apk
```
Ключ подписи: `android/chmogame.keystore` (пароль в `android/keystore.properties`). Не теряйте его — без него нельзя обновить установленное приложение.
